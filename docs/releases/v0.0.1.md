# SnapBot 0.0.1

把 [nanobot](https://github.com/HKUDS/nanobot) 0.3.5 包装成 Windows 桌面应用：
自带窗口（系统 WebView2），双击即用，**不需要装 Python、不需要命令行、不需要浏览器**。

## 下载

`SnapBot_0.0.1_x64-setup.exe` —— **259.3 MiB**（未压缩的安装程序，见下方说明）

```
SHA256  0D438D4D6AD28C2C6A05C05DD19809B0AF1E3CC12DBB7F71DBDFA77948CF199E
```

下载后可以这样核对（PowerShell）：

```powershell
Get-FileHash .\SnapBot_0.0.1_x64-setup.exe -Algorithm SHA256
```

|---|---|

> ⚠️ **本版本未签名。** 首次运行 Windows 会弹 SmartScreen「未知发布者」，
> 需要点「更多信息」→「仍要运行」。这是任何未签名分发包的必然表现，与程序本身无关。

## 首次使用

1. 双击安装 → 从开始菜单启动 **SnapBot**
2. 首次启动自动生成配置并拉起本地网关（约 5 秒），界面自动打开
3. 在 **Settings → Models** 里填入你的模型 API key —— **首次运行不含任何密钥**

## 卸载

开始菜单里有「**SnapBot 卸载**」，「设置 → 应用」里同样能找到。

卸载默认勾选「删除应用程序数据」，会一并删除 `%USERPROFILE%\.nanobot`
（**含 `config.json` 里的 API key 与会话历史，且不进回收站**）。
不想删就取消勾选。

## 与上游 nanobot 0.3.5 的差异

- 删除「自动任务」界面与后端路由 —— **保留 `cron` 引擎、`cron` 工具与本地触发器**，
  agent 仍能创建和管理定时任务，只是不再有专门的界面
- 删除浏览器端「注销」（保留供应商 OAuth 注销）
- 界面默认简体中文
- 认证自愈：网关凭据未就绪时轮询等待，不再要求用户手输密码
- 全部改动以补丁形式公开在 [`patches/`](https://github.com/Cretaceous-pc/SnapBot/tree/main/patches)，
  可对上游原版逐个 `git apply` 重放

## 已验证的行为

安装 / 独立运行（清空全部 `SNAPBOT_*` 环境变量后后端仍取自安装目录）/
覆盖安装不丢用户数据 / 卸载无残留 / 无控制台双击启动不崩 /
含中文与空格的安装路径 / 已删功能未进包（核对 `installer.nsi` 清单）。
逐项证据见 [docs/packaging.md](https://github.com/Cretaceous-pc/SnapBot/blob/main/docs/packaging.md)。

## 已知限制

- **未签名**（见上）
- **没有自动更新**：升级需手动下载新版本覆盖安装。
  覆盖安装**不会**丢用户数据（已验证）
- 目前只提供 x64 安装程序
